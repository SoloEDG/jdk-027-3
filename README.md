# Posture

表情包与海报排版生成器，提供底图管理、文字与贴纸图层、版式预设和指定尺寸导出。

## 本地启动

```bash
npm install
npm run dev
```

## Docker 启动

```bash
docker compose up --build
```

浏览器访问 `http://localhost:4173`。

## 文字样式

选中文字层后，右侧「文字样式」面板可实时调整填充色、描边色、描边宽度、字重、行高和对齐方式，画布与 PNG 导出共用同一套排版逻辑。

- **样式卡片**：调好样式后点「保存卡片」，即可把整套外观存成可复用卡片；点卡片本体应用到当前文字，「更新」用当前文字刷新卡片，「删除」只移除卡片。
- **覆盖值保护**：某层单独改过的属性会记为覆盖值。之后即使卡片被更新，这些属性仍保留该层自己的数值，未被改动的属性才跟随卡片；「恢复卡片样式」可清除覆盖。
- **不悬空**：卡片保存的是样式快照，不持有图层引用。删除文字层、切换版式预设或删除卡片都不会产生失效引用；删除卡片时，已应用的文字保持当前外观并转为自由样式。
- **长文案**：文字按 1080 设计宽度自动换行（中英文均可），每行严格采用设定行高，并按左/中/右对齐排布，画布与导出保持一致。
